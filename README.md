# π-NovoQC / CCT reproducibility code

This repository provides **reproducible reference implementations** for the manuscript:

**“Separate the wheat from the chaff: feature-level target–decoy competition enables trustworthy de novo peptide sequencing”**

The code is organized into **three self-contained subprojects**:

- `cct_qc_graphnovo/` — **CCT QC demo** on the GraphNovo test set (PSM-level + peptide-level QC), implemented as a runnable notebook.
- `xnovo_dda_finetune/` — **π-xNovo (DDA) fine-tuning** code (single-entry training script + modular package).
- `xnovo_dia_finetune/` — **π-xNovo (DIA) fine-tuning** code + optional helper scripts to build **spectrum-level training pairs** from run-level DIA identifications.

> **Data and pretrained weights are not stored in this repo.**  
> Datasets should be downloaded from the original public releases. Pretrained weights are intended to be hosted on Zenodo (see below).

## 1) Quick start (for reviewers)

### A. Reproduce CCT QC on GraphNovo (recommended entry point)
Go to `cct_qc_graphnovo/` and follow its README. In short:

1. Install dependencies:
   cd cct_qc_graphnovo
   pip install -r requirements.txt

2.	Download/prepare GraphNovo MGF files on your machine (not included here).
3.	Edit config_xNovo_DDA.yaml to point to your local MGF root directory.
4.	Run: Open xNovo_DDA_based_CCT_validation.ipynb and run top-to-bottom.
Expected outputs (written locally, typically git-ignored): checkpoints/, test_results/, log/, config_file/, and figure panels generated by the notebook.


### B. Fine-tune π-xNovo (DDA)
Go to xnovo_dda_finetune/:
1.	Install dependencies:
    cd xnovo_dda_finetune
    pip install -r requirements.txt
2.	Prepare training data in the expected MGF chunk format (see data/README.md).
3.	Edit configs/xnovo_dda_finetune.yaml and run:
    python main_xNovo.py --config configs/xnovo_dda_finetune.yaml --device cuda:0
Expected outputs: checkpoints/, test_results/, log/, config_file/

### C. Fine-tune π-xNovo (DIA)
Go to xnovo_dia_finetune/:
1.	Install dependencies:
    cd xnovo_dia_finetune
    pip install -r requirements.txt
2.	(Optional) Build spectrum–peptide training pairs for DIA using helper scripts:
	•	s1_psm_match.py — match run-level IDs to spectra using RT + isolation-window metadata
	•	s2_train_data_generation.py — generate MGF shards for training
	•	s3_train_data_offset.py — build lookup/index tables for faster loading
3.	Edit config_xNovo.yaml (or configs/xnovo_dia_finetune.yaml) and run:
    python main_xNovo.py --config config_xNovo.yaml
Expected outputs: checkpoints/, test_results/, log/, config_file/


## 2) Repository map (what each folder/file is for)

cct_qc_graphnovo/ — CCT QC demo (GraphNovo)
	•	xNovo_DDA_based_CCT_validation.ipynb
End-to-end runnable demo: candidate generation → feature pairing → strict/relaxed/combined scoring → FDR estimation & γ-adjustment → PSM-level and peptide-level QC plots.
	•	FDR.py
Core CCT logic: scoring, FDR/FDP computation, and interval-wise γ adjustment.
	•	model.py
π-xNovo-DDA model wrapper and feature extraction required by CCT.
	•	evaluate.py
Evaluation helpers (AA match / peptide recall, etc.).
	•	BLAST.py (optional)
Helper utilities for peptide-to-protein mapping via BLAST+ (only needed for optional downstream steps).
	•	config_xNovo_DDA.yaml
Configuration template (paths + key hyperparameters).
	•	requirements.txt, CITATION.cff, LICENSE, THIRD_PARTY_NOTICES.md
Dependencies, citation metadata, licensing, and third-party notices.
	•	depthcharge_new/, pyteomics_master/
Vendored dependencies for reproducibility (keep original licenses; see notices).

xnovo_dda_finetune/ — π-xNovo (DDA) fine-tuning
	•	main_xNovo.py
Minimal entry point for fine-tuning / training.
	•	configs/xnovo_dda_finetune.yaml
Example training configuration.
	•	xnovo_dda/
Python package with the model (model.py), data loader (dataset.py), evaluation (evaluate.py), and utilities (utils.py).
	•	data/README.md
Required data layout and MGF chunk format.
	•	weights/README.md
Where to place pretrained weights (downloaded separately).
	•	requirements.txt, CITATION.cff, LICENSE

xnovo_dia_finetune/ — π-xNovo (DIA) fine-tuning + DIA data prep
	•	main_xNovo.py, dataset.py, model.py, utils.py, evaluate.py
Core training pipeline.
	•	s1_psm_match.py, s2_train_data_generation.py, s3_train_data_offset.py
Optional helper scripts to convert run-level DIA identifications to spectrum-level pairs for training.
	•	config_xNovo.yaml / configs/xnovo_dia_finetune.yaml
Training configuration (edit paths).
	•	depthcharge_new/, pyteomics_master/
Vendored dependencies (see THIRD_PARTY_NOTICES.md).
	•	requirements.txt, CITATION.cff, LICENSE, THIRD_PARTY_NOTICES.md
